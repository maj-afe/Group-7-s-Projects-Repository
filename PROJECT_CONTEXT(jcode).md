## 1. Project Overview

### 1.1 Core Purpose

BUG is a **multimodal, fully offline, hands-free desktop control system** that enables users—particularly those with motor disabilities—to control their computer using **facial gestures** (head movement, mouth opening) and **voice commands**. The system combines MediaPipe face landmark tracking for cursor control with Faster-Whisper speech recognition for command execution.

### 1.2 Key Features

| Feature | Input Modality | Output | Key Modules |
|---|---|---|---|
| Head-tracking cursor control | Webcam (face landmarks) | Mouse movement (pyautogui) | `app/camera/facecursor.py`, `app/camera/face_cursor_windows_varient.py` |
| Mouth-click | Webcam (lip distance) | Left mouse button down/up | `app/camera/face_cursor_windows_varient.py` |
| Head-gesture scrolling | Webcam (vertical head tilt) | Mouse wheel scroll | `app/camera/face_cursor_windows_varient.py` |
| Head-gesture back navigation | Webcam (horizontal head turn) | Alt+Left browser back | `app/camera/face_cursor_windows_varient.py` |
| Voice command execution | Microphone → Faster-Whisper | Keyboard/mouse shortcuts | `app/voice/speech_recognition.py`, `app/voice/command_handler.py` |
| Voice dictation | Microphone → Faster-Whisper | Typed text (pyautogui.write) | `app/voice/command_handler.py` (`dictation_mode`) |
| Power control (lock/sleep/restart/shutdown) | Voice command | Windows system power APIs | `app/system/system_controller.py` via `SignalBridge` |

## 4. Architecture & Design Patterns

### 4.1 Layered Architecture

The application follows a **four-layer architecture** with strict dependency direction (UI → Camera → Voice → System). The `app/` package is structured into sub-packages that communicate through Qt signals, not direct cross-layer imports.

```
┌─────────────────────────────────────────────────────────┐
│                    app/ui/  (PySide6 GUI)                 │
│  MainWindow ←→ DashboardWidget, VoiceOverlay, Dialogs   │
├─────────────────────────────────────────────────────────┤
│                   app/camera/  (Face Tracking)           │
│    CameraThread(QThread) → MediaPipe → pyautogui         │
├─────────────────────────────────────────────────────────┤
│                   app/voice/  (Voice Processing)        │
│  VoiceAssistant → SpeechRecThread → [AudioCapture       │
│  → AudioProcessor → SileroVAD → WhisperEngine]          │
│  → CommandHandler → pyautogui / WindowManager /          │
│  SignalBridge → SystemController                        │
├─────────────────────────────────────────────────────────┤
│                  app/system/  (System Control)           │
│  SignalBridge (singleton) ↔ SignalSlot connections       │
│  SystemController (Windows API via ctypes/pywin32)      │
│  WindowManager (Win32 via pywin32 + psutil)               │
└─────────────────────────────────────────────────────────┘
```

### 4.2 Threading Model

The application uses **Qt's QThread model** to keep the GUI responsive. All background work runs on dedicated QThreads; the main thread handles Qt event processing only.

| Thread | Class | File | Role |
|---|---|---|---|
| Main (GUI) | `MainWindow(QMainWindow)` | `app/ui/main_window.py` | Event loop, widget rendering, signal-slot dispatch |
| Camera | `CameraThread(QThread)` | `app/camera/face_cursor_windows_varient.py` | Webcam capture, MediaPipe inference 30 FPS, emits `frame_ready(QImage)` + `status_update(str)` |
| Voice Recognition | `SpeechRecognitionThread(QThread)` | `app/voice/speech_recognition.py` | Audio capture → VAD → Whisper inference (~200–800 ms per segment) |
| Scroll (daemon) | `threading.Thread` | `app/voice/command_handler.py` (`_scroll_loop`) | Continuous scroll loop (started/stopped per command) |

**Key constraint:** Whisper inference is **synchronous** and blocks the `SpeechRecognitionThread` for 200–800 ms. This is acceptable because it runs in a separate QThread. The UI remains responsive.

### 4.3 Key Design Patterns

| Pattern | Implementation | Files |
|---|---|---|
| **Singleton** | `SignalBridge` uses `__new__` override (`_instance` guard + `_initialized` flag) so `SignalBridge()` and `SignalBridge.get_instance()` return the same object | `app/system/signal_bridge.py` |
| **Observer / Signal-Slot** | Qt signals (`command_recognized`, `frame_ready`, `status_update`, `error_occurred`, `request_power_confirmation`) connect background threads to the GUI | All QThread/QObject subclasses |
| **State Machine** | `SileroVAD` has three states: `WAITING` → `SPEAKING` → `DONE`; transitions driven by speech probability threshold | `app/voice/vad.py` |
| **Strategy (fuzzy matching)** | `CommandHandler._fuzzy_match()` uses `rapidfuzz.process.extractOne` with `token_set_ratio`; single-word inputs are bypassed to avoid false positives | `app/voice/command_handler.py` |
| **Guard / Circuit Breaker** | `CommandHandler.enabled` flag: emergency stop disables all commands except "enable control" which always bypasses | `app/voice/command_handler.py` |
| **Cooldown** | Per-command key (not raw transcript) cooldown at 1.5 seconds; aliases for the same action share one cooldown | `app/voice/command_handler.py` |
| **Dependency Injection (partial)** | `VoiceAssistant` creates `CommandHandler` internally; MainWindow creates `SignalBridge`, `SystemController`, `VoiceAssistant` as separate objects and wires them via Qt signals | `app/ui/main_window.py` |
| **Pass-Through Fallback** | `AudioProcessor` degrades to raw PCM pass-through if `pywebrtc-audio` is not installed | `app/voice/audio_processor.py` |

### 4.4 Module Boundaries & Import Rules

- **`app/` is the canonical package.** All intra-package imports use absolute paths anchored on `app.` (e.g., `from app.voice.command_handler import CommandHandler`).
- **`app/main.py`** adds the project root to `sys.path` so `app.*` imports work when run directly or frozen with PyInstaller.
- **`voice/` (standalone)** uses relative imports (`.speech_recognition`, `.command_handler`) and cannot import from `app/` — it is a parallel, independent codebase.
- **`Group-7-s-Projects-Repository/`** is a nested git repository with its own `.git` directory. It is not importable from the root project and is excluded from all Python path operations.
- **Windows-only imports** (`win32gui`, `win32con`, `ctypes.windll`) are guarded with `try/except` in `command_handler.py` and `system_controller.py`, allowing the code to be imported on Linux/macOS (modules become `None`, commands are skipped).

## 5. Data Flow (End-to-End Pipelines)

### 5.1 Voice Pipeline

```
Microphone (16 kHz, 16-bit, mono)
  │
  ▼  sounddevice callback (10 ms int16 PCM frame per tick)
AudioCapture._callback()
  │  queue.put_nowait() — non-blocking, thread-safe
  ▼  (queue.Queue, maxsize=QUEUE_MAX_FRAMES)
AudioProcessor.process()   ┄  WebRTC APM: Noise Suppression + AGC + HPF
  │  int16 bytes → cleaned int16 bytes (or pass-through if pywebrtc-audio missing)
  ▼
SileroVAD.process_frame()   ┄  accumulates 160-sample frames into 512-sample chunks
  │  Runs ONNX inference → speech_prob ∈ [0, 1]
  │  State machine: WAITING → (prob > 0.5) → SPEAKING → (prob < 0.5 × POST_ROLL) → emit
  │  Emits: (audio_np: float32[-1,1], sample_rate=16000) via callback
  ▼
SpeechRecognitionThread._on_vad_segment()  ┄  queue.Queue(maxsize=4)
  │  put_nowait((audio_np, sr)) — bounded, drops oldest on overflow
  ▼
WhisperEngine.transcribe()  ┄  Faster-Whisper (base, CPU, int8)
  │  beam_size=3, best_of=3, temperature=0.0 (greedy), initial_prompt=command vocabulary
  │  Returns: lowercased transcript string
  ▼
CommandHandler.normalize()  ┄  lowercase, strip punctuation, collapse whitespace, deduplicate
  │
  ├── [dictation_mode] → pyautogui.write(text + " ")
  │
  └── _fuzzy_match()  ┄  rapidfuzz token_set_ratio (cutoff=80, multi-word only)
       │
       ▼
    CommandHandler.execute()  ┄  matches transcript → pyautogui / webbrowser / subprocess
       │
       ├── mouse click/double/right-click → pyautogui.click/doubleClick/rightClick
       ├── scroll → pyautogui.press("pagedown"/"pageup")
       ├── browser nav → pyautogui.hotkey("alt","left" / "ctrl","t" / "ctrl","r")
       ├── tabs → pyautogui.hotkey("ctrl","tab" / "ctrl","shift","tab")
       ├── zoom → pyautogui.hotkey("ctrl","="/-"/"+0)
       ├── fullscreen → pyautogui.press("f11")
       ├── text/clipboard → pyautogui.hotkey("ctrl","a/c/v/x/y/z/backspace")
       ├── keyboard keys → pyautogui.press("enter"/"tab"/"esc"/"backspace")
       ├── window mgmt → WindowManager.switch_to_window / minimize / maximize / move
       ├── media → pyautogui.press("playpause"/"volumeup"/"volumedown"/"nexttrack")
       ├── browser sites → webbrowser.open(url)
       ├── dynamic app launch → PowerShell Get-StartApps + subprocess.Popen
       ├── dictation toggle → self.dictation_mode = True
       ├── head/mouth/calibration → returns command key (MainWindow handles)
       ├── power commands → SignalBridge.request_power_confirmation.emit(action)
       │     └→ MainWindow._show_power_confirmation_dialog() → QMessageBox → SystemController
       └── unknown → return None, log "Unknown command"
       │
       ▼
    command_executed.emit(transcript, command_key)  ┄  Qt signal
       │
       ▼
    MainWindow.update_voice_command()  ┄  updates dashboard, shows VoiceOverlay
```

### 5.2 Camera Pipeline

```
Webcam (USB)
  │  cv2.VideoCapture(0, cv2.CAP_DSHOW)  (DirectShow on Windows)
  ▼
CameraThread.run()
  │  cv2.flip(frame, 1) — mirror image
  │  cv2.cvtColor(frame, BGR→RGB)
  ▼
MediaPipe FaceLandmarker (face_landmarker.task, VIDEO mode, 1 face)
  │  detects 468 facial landmarks + iris tracking
  │  anchor_point = landmark[168]  (nose bridge)
  │  upper_lip = landmark[13], lower_lip = landmark[14]
  ▼
Gesture Processing:
  ├── dx/dy relative to calibrated center → deadzone → EMA filter → pyautogui.moveTo()
  ├── vertical head tilt (dy) → pyautogui.scroll() (speed ∝ |dy|)
  ├── horizontal head turn (dx > ±0.15) → pyautogui.hotkey("browserback")
  ├── mouth_distance = hypot(lip13 - lip14) → >0.035 threshold → mouseDown/mouseUp
  └── calibration: center_x/center_y set from neutral nose position
  │
  ▼
frame_ready.emit(QImage)  ┄  Qt signal
  │
  ▼
MainWindow.update_camera_frame()  ┄  scales and displays on DashboardWidget.camera_feed_label
```

### 5.3 Power Command Flow (Cross-Thread)

This is the most complex signal path in the system:

```
Voice command: "shutdown computer"
  │
  ▼
CommandHandler.execute("shutdown computer")
  │  self._is_on_cooldown("shutdown_computer") — checks
  │  self._trigger_power_confirmation("shutdown")
  │    → self.signal_bridge.request_power_confirmation.emit("shutdown")
  │       (SignalBridge is a singleton — same instance as MainWindow's)
  ▼
MainWindow._show_power_confirmation_dialog("shutdown")
  │  QMessageBox (Warning icon, Yes/No, default=No)
  │  if Yes → SystemController.shutdown_computer()
  │           → subprocess.run(["shutdown", "/s", "/t", "0", "/f"])
  ▼
SystemController._last_error set on failure
```

### 5.4 Window Control Flow

```
Voice command: "switch to chrome"
  │
  ▼
CommandHandler.execute("switch to chrome")
  │  regex: r"^switch to\s+(.+)$" → app_name = "chrome"
  │  self.window_manager.switch_to_window("chrome")
  ▼
WindowManager.find_window("chrome")
  │  Step 1: exact process name match (case-insensitive)
  │  Step 2: partial process name match (substring)
  │  Step 3: partial window title match (substring)
  │  Step 4: word-set subset match
  │  Returns: (hwnd, title, process_name) or None
  ▼
WindowManager.switch_to_window()
  │  if minimized → win32gui.ShowWindow(hwnd, SW_RESTORE)
  │  win32gui.SetForegroundWindow(hwnd)
```

## 6. Key Components & Entry Points

### 6.1 Entry Point: `app/main.py`

**Role:** Qt application bootstrap. Adds project root to `sys.path` (handles both frozen and unfrozen execution), creates `QApplication`, sets "Segoe UI" font, instantiates `MainWindow`, shows it, and enters `app.exec()`.

**Key behavior:** When frozen with PyInstaller (`sys.frozen`), it sets the project root to `sys._MEIPASS`. When running from source, it computes the parent of `app/` (i.e., the repo root).

| `disable_head_tracking` | `camera_thread.set_cursor_control(False)` |

| `control_enabled` | `start_all()` (restarts voice + cursor + auto-calibrate) |

### 6.5 System Layer

#### `app/system/signal_bridge.py` (SignalBridge — 25 lines)

A proper Qt **singleton** (via `__new__` override) that carries GUI-request signals from background threads to the main thread:

```python
class SignalBridge(QObject):
    request_power_confirmation = Signal(str)  # 'lock', 'sleep', 'restart', 'shutdown'
    _instance = None
    
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
    
    def __init__(self):
        if not hasattr(self, '_initialized'):
            super().__init__()
            self._initialized = True
```

Both `MainWindow.setup_connections()` (via `SignalBridge()`) and `CommandHandler.__init__` (via `SignalBridge.get_instance()`) obtain the **same singleton instance**, so signals emitted in the voice thread are received by the GUI thread.

#### `app/system/system_controller.py` (SystemController — 66 lines)

Windows-only power control using `ctypes.windll`:
- `lock_computer()` → `user32.LockWorkStation()`
- `sleep_computer()` → `SetThreadExecutionState` + `powrprof.SetSuspendState(0,0,0)`
- `restart_computer()` → `subprocess.run(["shutdown", "/r", "/t", "0", "/f"])`
- `shutdown_computer()` → `subprocess.run(["shutdown", "/s", "/t", "0", "/f"])`

**All methods return `bool`** and store the last error in `self._last_error` — no exceptions are raised on failure.

#### `app/system/window_manager.py` (WindowManager — 220 lines)

Win32 window management via `win32gui`, `win32con`, `win32process`, `psutil`. Four-step window finding strategy:
1. Exact process name match
2. Partial process name match (substring)
3. Window title substring match
4. Word-set subset match (all query words appear in title)

Methods: `switch_to_window()`, `minimize_window()`, `maximize_window()`, `move_active_window()`, `close_active_window()`.

### 6.6 Command Engine (`app/voice/command_handler.py`)

**120 lines** — the central voice command dispatcher. See Section 11 for the full command map.

Key subsystems:
- **`normalize(text)`** → lowercases, strips punctuation `[.,!?;:'"()\[\]{}<>]`, collapses whitespace, then calls `_deduplicate()` to fix Whisper's word-repetition artifacts
- **`_deduplicate(text)`** → detects repeated patterns (e.g., "copy copy" → "copy") by trying unit lengths from 1 to n//2
- **`_fuzzy_match(text)`** → rapidfuzz `token_set_ratio` with `score_cutoff=80`; only multi-word, non-"search" inputs
- **`_is_on_cooldown(cmd_key)`** → per-command-key cooldown (1.5s); aliases share cooldown
- **`_trigger_power_confirmation(action)`** → emits `SignalBridge.request_power_confirmation`
- **`_get_installed_apps()`** → PowerShell `Get-StartApps` → JSON parsed into `{name_lower: (display_name, app_id)}`
- **`open_installed_app(name)`** → exact/partial match → `explorer.exe shell:AppsFolder\{app_id}`; fallback to `C:\Program Files\...\` glob
- **`execute(transcript)`** → the main dispatch method (see command list in Section 11)
